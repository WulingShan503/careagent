# 澄初个人护理 · AI 金牌导购

题目 08 作业提交。一个可现场试用的导购 Agent，产品事实与规则边界均来自题目提供的品牌手册。

## 二、使用说明

**支持的输入**：自然语言文字对话，无需按格式提问。

顾客可以直接说日常说法，例如：

| 输入示例 | Agent 行为 |
|---|---|
| 「想买洗面奶，皮肤有点干」 | 推荐 P101，说明无香型、低泡的适配理由 |
| 「我是油皮，预算 400 以内」 | 推荐 P102 + P203，报出准确合计价 |
| 「我对香味很敏感」 | 避开带香的 P102/P203，改推无香型 P101/P202 |
| 「我想改善皮肤粗糙」 | 先做果酸前置筛查，不直接推 P201 |
| 「有赠品吗 / 网上更便宜吗 / 能退货吗」 | 说明手册未覆盖，需向门店或系统确认 |
| 「用了之后有点刺痛」 | 建议停止刺激性尝试并咨询专业人士，不作诊断 |

界面左侧常驻完整产品目录、组合价与「手册未覆盖话题」清单，便于现场核对 Agent 输出是否与手册一致。

## 三、规则使用说明

**核心设计：产品事实与规则边界不交给大模型判断，走确定性代码。**

题目要求「判断依据来自题目给定规则，不允许只依赖大模型常识自由判断」。据此把职责切成三层：

```
顾客输入
   ↓
① 确定性护栏层（guard.py）── 命中即用固定话术直接回复，不调用模型
   ├─ 皮肤不适 / 医疗诉求   → 安全话术 + 建议咨询专业人士
   ├─ 手册未覆盖政策话题     → 说明需向门店或系统确认
   └─ 果酸产品（P201）      → 先做敏感与使用经验筛查
   ↓ 未命中
② 大模型生成（agent.py）── 手册全文注入 system prompt，模型只负责组织语言
   ↓
③ 输出校验（guard.py）── 检查回复是否越界
   ├─ 禁用表达（治愈/保证有效/绝对不过敏/马上见效…）→ 标记
   └─ P301 连带推荐且无旅行需求 → 自动移除该段
```

### 手册规则如何落地

| 手册规则 | 实现方式 |
|---|---|
| 6 个 SKU 的名称、规格、价格、特点、适用、限制 | `kb.py` 逐字硬编码，唯一事实来源 |
| 两个组合价 428 / 368 | 代码校验等于成员单价之和，**无折扣**，禁止说「优惠/省钱/划算」 |
| P201 果酸：敏感、受损或不适不推荐 | 触发果酸话题时强制前置筛查；判定不适后加入屏蔽名单 |
| P301 仅在旅行需求明确时连带推荐 | 从顾客原话确认旅行需求；未确认时自动移除模型的 P301 段落 |
| P102/P203 带香味，P101/P202 无香型 | 香味敏感写入会话状态，注入 prompt 影响推荐 |
| 不作医疗诊断 | 不适词表前置拦截，走固定安全话术 |
| 未提供促销/赠品/线上同价/退换货/渠道授权政策 | 话题词表 + 同义词扩展命中即转交确认 |
| 不制造焦虑、不夸大、不强推连带 | 品牌约束注入 prompt + 输出层禁用词校验 |

### 一处关键实现

手册术语与顾客说法不一致，直接匹配会漏。例如手册写「线上同价」，顾客说的是「网上更便宜」。因此为 5 个未覆盖话题各配了同义词表（`kb.UNCOVERED_ALIASES`），「有什么活动」→ 促销、「这是正品吗」→ 渠道授权，均能命中。

## 四、输出格式说明

Agent 回复为自然语言对话（导购场景不适合表格化输出），但受以下约束：

| 字段 | 保证 |
|---|---|
| SKU 编号 | 提到产品必带编号，只可能是 P101/P102/P201/P202/P203/P301 |
| 价格 | 与手册完全一致；组合价按单价相加 |
| 推荐理由 | 对应顾客说过的需求，不泛泛而谈 |
| 限制提示 | 涉及 P201 时提示防晒与适用边界 |
| 无法判断 | 手册未覆盖 → 明确说明需向门店或系统确认 |
| 人工复核 | 皮肤不适 → 建议咨询专业人士 |

命中规则层的回复会在界面上附一个「判定依据」折叠块，展示**触发词**与**依据的手册原文规则**，便于现场验证判断来源。

## 五、自测样例

以下为实际运行结果（真实模型调用，非构造）。

### 样例 1：香味敏感 → 避开带香产品

**输入**：`我对香味很敏感，推荐个保湿的`

**输出**：
> 明白了，您是敏感倾向肤质，又对香味比较敏感，主要想做好保湿。
>
> 那可以考虑 **P202 屏护神经酰胺保湿乳 50ml｜259 元** —— 它是无香型，含神经酰胺类保湿成分，适合干燥或屏障脆弱倾向的皮肤。
>
> 搭配清洁的话，**P101 云感氨基酸舒润洁面乳 150ml｜169 元** 也是无香型…

**验证点**：正确避开带香的 P102、P203；SKU 与价格均与手册一致；无违禁表达。

### 样例 2：手册未覆盖话题 → 转交确认

**输入**：`网上更便宜能同价吗`

**输出**：
> 关于线上同价这部分，我手上的品牌资料里没有相关政策说明，所以不能给您一个确定的答复 —— 需要向门店或系统确认。
>
> 如果您方便的话，可以到门店由店员帮您查一下系统，那边的信息会比我这里准确。产品本身的成分、适用情况和价格我可以直接告诉您。

**验证点**：未调用大模型，走确定性话术；没有编造任何比价或折扣政策。

### 样例 3：皮肤不适 → 安全边界

**输入**：`用了之后有点刺痛`

**输出**：
> 听起来您的皮肤现在状态不太稳定，这种情况我不方便替您判断原因。
>
> 建议先暂停正在使用的功效类产品，尤其是含酸类等有刺激性的产品，让皮肤先安静一段时间；如果不适持续或加重，请咨询皮肤科医生或专业人士。
>
> 等状态恢复稳定之后，我再帮您看看日常清洁和保湿可以怎么安排。

**验证点**：不作诊断；建议停止刺激性尝试；同时将 P201 加入本次会话屏蔽名单。

### 样例 4：果酸前置筛查

**输入**：`我想改善皮肤粗糙`

**输出**：
> 在聊这类产品之前，有两件事想先确认一下：
>
> 1. 您的皮肤目前有没有敏感、刺痛或者正在不适的情况？
> 2. 之前有用过果酸或类似的焕肤产品吗？
>
> 这两点会直接影响它适不适合您，所以我想先问清楚，而不是直接推荐。

**验证点**：未直接推 P201；追问对应手册对该产品的限制条件。

### 样例 5：拒绝不合规连带推荐

**输入**：`预算只有150，想要洁面和保湿都买`

裸模型会拿 49 元的 P301（旅行分装瓶）去凑预算 —— 这属于强推连带购买，且 P301 不是护肤功效产品。输出校验层检测到顾客未提旅行需求，自动移除该段并在界面标注：

> ⚙️ 输出校验　已移除 P301 连带推荐：顾客未明确旅行携带需求（手册限制）

## 六、本地运行

```bash
pip install streamlit openai
```

创建 `.streamlit/secrets.toml`：

```toml
DASHSCOPE_API_KEY = "你的通义千问 API Key"
```

启动：

```bash
streamlit run app.py
```

## 七、文件说明

| 文件 | 内容 |
|---|---|
| `kb.py` | 产品知识库，逐字取自品牌手册，零推测补全 |
| `guard.py` | 确定性护栏层：场景拦截 + 输出校验 |
| `agent.py` | 千问调用、手册注入、需求结构化抽取 |
| `app.py` | Streamlit 界面与三层流程编排 |

技术栈：Streamlit 1.63 · 通义千问 qwen-plus（OpenAI 兼容接口）· Python 3.14
